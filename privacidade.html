Política de Privacidade

SystemSeg Core OS • Última atualização: 29/09/2026

Esta Política de Privacidade descreve como o SystemSeg Core OS, operado pela SystemSeg Tecnologia, trata informações utilizadas para criar, digitalizar, gerar e arquivar ordens de serviço.

1. Dados tratados pelo sistema

O sistema pode tratar informações inseridas pelo usuário nas ordens de serviço, como nome do cliente, endereço, data do serviço, técnico responsável, itens e valores, observações, assinaturas e fotografias opcionais anexadas à O.S. Quando a função de digitalização é usada, a imagem enviada é processada no navegador para auxiliar na transcrição e no recorte das assinaturas.

2. Integração com a Conta do Google

Quando o usuário conecta uma Conta do Google, o SystemSeg Core OS solicita autorização OAuth para identificar a conta e acessar o Google Drive com o escopo drive.file. Esse acesso é usado para criar, localizar, atualizar e organizar somente os arquivos e pastas utilizados ou criados pelo aplicativo, como PDFs de ordens de serviço.

Dados do Google: o aplicativo não solicita acesso geral irrestrito a todos os arquivos do Google Drive. O acesso solicitado é limitado ao escopo necessário para os arquivos usados pelo SystemSeg Core OS.

3. Microfone e ditado por voz

Quando o usuário toca no ícone de microfone de um campo, o navegador pode solicitar permissão para usar o microfone. O recurso de reconhecimento de voz é fornecido pelas capacidades do navegador/dispositivo. O SystemSeg Core OS utiliza o resultado reconhecido apenas para preencher o campo selecionado.

4. Fotografias anexadas

As fotografias anexadas são opcionais. Elas são redimensionadas e comprimidas no navegador e inseridas no PDF final da ordem de serviço. Quando o PDF é enviado ao Google Drive, as fotografias passam a fazer parte do próprio documento PDF.

5. Como os dados são armazenados

  • Os PDFs de O.S. são armazenados na Conta do Google Drive autorizada pelo usuário.
  • O servidor do sistema usa Cloudflare Workers e Workers KV para armazenar, de forma técnica, a autorização persistente do Google, o e-mail da conta conectada e chaves de dispositivos autorizados.
  • No navegador, podem ser armazenados o endereço do servidor, uma chave de dispositivo e rascunhos da O.S. usando armazenamento local do navegador.

6. Compartilhamento de dados

O SystemSeg Core OS não vende dados pessoais. Os dados são transmitidos apenas aos serviços necessários para executar as funções solicitadas, como Google Drive/Google OAuth e Cloudflare, conforme a operação técnica do sistema.

7. Revogação e exclusão do acesso

O usuário pode clicar em Desconectar conta no painel do SystemSeg Core OS. Essa ação remove a autorização armazenada pelo sistema, invalida os dispositivos vinculados e solicita a revogação do token no Google. O usuário também pode revisar ou revogar o acesso do aplicativo diretamente nas configurações da Conta do Google.

8. Segurança

O Client Secret e o token de atualização do Google não são armazenados no HTML público do GitHub Pages. As credenciais do servidor ficam na infraestrutura do Cloudflare Worker. Apesar das medidas adotadas, nenhum sistema conectado à internet pode garantir segurança absoluta.

9. Retenção

Os documentos permanecem no Google Drive até que sejam removidos pelo proprietário da conta ou substituídos pelo próprio fluxo do sistema. Dados técnicos de autorização permanecem enquanto a conta estiver conectada e podem ser apagados ao desconectar.

10. Contato

Para dúvidas sobre esta Política ou sobre o uso dos dados, entre em contato pelo e-mail systemsegtecnologia@gmail.com.

11. Alterações desta Política

Esta Política pode ser atualizada para refletir mudanças no sistema, nos serviços integrados ou em requisitos legais e de plataforma. A versão vigente será sempre publicada nesta página.
